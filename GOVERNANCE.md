# Governance

## Participation

Anyone may open issues and discussions, contribute a pull request, review a
proposal, or improve documentation. Contributions are governed by the MIT
license and Code of Conduct. Contributors do not receive repository write access
automatically; changes are reviewed through pull requests.

## Maintainer

The initial maintainer is [Rechcel Toledo (@phcodesage)](https://github.com/phcodesage).
Maintainers manage reviews, merges, releases, moderation, and security response.

## Decisions

Routine fixes are decided in pull request review. Larger changes should begin in
an issue or discussion describing the problem, options, tradeoffs, and proposed
behavior. Decisions and their rationale should be recorded publicly, except for
confidential security or conduct matters. The maintainer makes the final decision
when consensus cannot be reached.

## Becoming a maintainer

Contributors with a sustained record of thoughtful contributions and reviews can
express interest in a public discussion. The current maintainer considers project
needs, judgment, reliability, and commitment to the Code of Conduct. Any expanded
role and access level should be recorded in this file. There is no minimum
donation, employment requirement, or promised contribution count.

Changes to governance should be proposed through a pull request so the community
can discuss them.
